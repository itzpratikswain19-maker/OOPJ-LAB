# OPPJ-LAB

## Object-Oriented Programming with Java Lab

This repository contains the programs and assignments completed as part of the **Object-Oriented Programming with Java (OPPJ) Lab**.

The repository is organized assignment-wise, with each assignment containing five Java programs unless otherwise specified.
